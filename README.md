# antonr8.github.io

Портфолио — https://antonr8.github.io

Статический сайт на GitHub Pages (ветка `main`, папка `/`).

## Структура

- `index.html` — страница целиком (вёрстка и стили инлайном)
- `media/` — картинки и скрипты страницы
- `assets/fingerlakes/demo.mp4`, `assets/fishgame/demo.mp4` — видео-демо проектов

Остальное содержимое `assets/` — исходники, которые на сайте не используются; они исключены через `.gitignore`.
